
## Designs Included

### 1. Bulk Upload & Verification Queue — Table View (#879)
- Create a table-based interface for managing multiple file uploads.
- Display individual upload and verification progress.
- Present file details and relevant queue statuses clearly.
- Apply the existing Dark Mode visual language.

### 2. API Usage Analytics — Grid/Charts View (#796)
- Visualize API request activity and usage trends.
- Present storage consumption and rate-limit information.
- Organize analytics into readable metric cards and charts.
- Follow the platform's Light Mode styling.

### 3. User Profile & Settings (#882)
- Provide profile controls for updating email and avatar.
- Include Web2 password management.
- Organize account settings into an intuitive layout.
- Maintain the Dark Mode design system.

### 4. Wallet Management & Web3 Connections (#883)
- Design wallet connection and disconnection controls.
- Display the connected Freighter wallet and associated `stellarPublicKey`.
- Make wallet connection status easy to identify.
- Follow the platform's Dark Mode styling.

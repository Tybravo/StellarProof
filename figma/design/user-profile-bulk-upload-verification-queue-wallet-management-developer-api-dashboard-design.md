
## Screens Designed

### 1. User Profile & Settings — Light Mode (#790)
- Profile form for updating email address and avatar.
- Web2 password update interface.
- Clean form layouts with clear labels, validation states, and action feedback.
- Consistent Light Mode styling.

### 2. Bulk Upload & Verification Queue — Grid View (#878)
- Enterprise-focused interface for uploading multiple files.
- Grid-based presentation of uploaded files.
- Individual upload progress indicators and verification statuses.
- Dark Mode styling aligned with the platform's visual system.

### 3. Wallet Management & Web3 Connections — Light Mode (#791)
- Interface for connecting and disconnecting Freighter wallets.
- Display of the connected wallet's associated `stellarPublicKey`.
- Clear wallet connection states and account information.
- Light Mode visual consistency.

### 4. Developer API Dashboard — Light Mode (#795)
- Dashboard interface for generating API keys.
- Controls for revealing and revoking existing keys.
- Clear presentation of API key information and available actions.
- Light Mode styling consistent with StellarProof's developer experience.

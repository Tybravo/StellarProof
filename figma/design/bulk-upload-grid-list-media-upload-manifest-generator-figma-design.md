
## Design Coverage

### 1. Bulk Upload & Verification Queue — Grid View (#786)
- Create a visual grid layout for managing multiple file uploads.
- Display individual upload progress and processing states.
- Organize file previews and relevant status information into clear cards.
- Ensure the layout adapts to different screen sizes.

### 2. Bulk Upload & Verification Queue — List View (#788)
- Provide a structured list alternative for enterprise bulk uploads.
- Present file details, progress indicators, and verification statuses in readable rows.
- Maintain consistent visual behaviour with the Grid View.

### 3. Media Upload Step — Verification Wizard (#370)
- Design a drag-and-drop upload area for images and videos.
- Include clear upload instructions and supported interaction states.
- Make file selection and upload feedback easy to understand.

### 4. Manifest Generator — Verification Wizard (#371)
- Design a metadata form for entering the content title, creator, and description.
- Present the information required to generate a JSON/XML manifest.
- Establish a clear form hierarchy with appropriate input guidance and validation states.
